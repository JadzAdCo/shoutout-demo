# Baller's Express Business — Cursor handoff

1. Extract this folder into your existing project or attach its contents to Cursor.
2. Open `CURSOR_PROMPT.md` and ask Cursor to implement it in the current codebase.
3. Supply the PNG as the primary visual asset. The JPG and SVG are alternate formats of the same base artwork.

The template leaves the two lower-left rows blank for a name/social media @handle and company name. Cursor should retain and align the existing face-upload feature in the upper-left medallion.

Files:
- `CURSOR_PROMPT.md`: complete implementation instructions.
- `assets/ballers-express-business.png`: primary base image.
- `assets/ballers-express-business.jpg`: high-quality JPEG.
- `assets/ballers-express-business.svg`: embedded-raster SVG; not separate editable vector elements.

The heading is matched visually to the existing lettering; the exact original font is not verified. The artwork is reconstructed from the supplied reference. The package contains instructions/assets, not a patch against your unseen repository.
