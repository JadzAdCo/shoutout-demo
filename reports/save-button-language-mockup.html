Rules: if the picked language equals the current page language, the button is the single translated word and no hint shows. If they differ, the button shows picked-language word on top and the current-language word underneath, plus the two-line hint. Picking a language only previews the button. Nothing switches until Save is tapped. Works for all 11 languages, from any starting language (for example, a French page with Deutsch picked shows "Speichern / Enregistrer").
