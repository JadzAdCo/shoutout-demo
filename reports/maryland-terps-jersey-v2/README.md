2. In Cursor Agent, attach CURSOR_MASTER_PROMPT.md, IMPLEMENTATION_CONTRACT.md and SOURCES.md, and the assets/reference image.
3. Tell Cursor: “Implement this package in the existing repository. Inspect the actual ShoutOut/editor/player integration, then continue through implementation and verification. Follow the asset readiness rules.”

Contents: variant master prompt; shared implementation contract; verified-source research; supplied visual reference; machine-readable contract; pure TypeScript timing starter. This is a prompt/implementation package, not finished garment art or a runnable FloqR application. Source assets still need preparation and exact front/back verification. No image generator was used to fabricate an official jersey.

Customer fields: Name, Number, optional ShoutOut. Jersey pair 7 seconds; separate message 5 seconds. A blank message means jersey only for 7 seconds. Display sizes are centimeters, and actual pixels must come from the target hardware.

Version 2 adds Maryland basketball to the shared engine and is compatible with Version 1; install both packages to build both team families. Do not treat package versions as jersey seasons.
