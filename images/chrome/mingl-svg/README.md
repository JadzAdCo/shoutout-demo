# Mingl — Site Chrome SVG Logo & Icon Kit

FLOQR store path: `images/chrome/mingl-svg/`. Placement recommendation (Search icon + FloqMedia logo): **`FLOQR.md`**. Not live until wired.

**Purpose:** Editable, monochrome, theme-inheriting vector assets for the Mingl feature and brand within FLOQR.

- `icons/`: six standalone symbols (including recommended compact and orbit variants).
- `logos/`: four editable text-based logo arrangements.
- `components/`: four reusable individual SVG parts.
- `examples/preview.html`: offline asset contact sheet.
- `examples/site-chrome.css`: theme integration illustration.
- `CURSOR_IMPLEMENTATION.md`: production integration requirements.

All SVGs are colorless in the sense that **no fixed palette** is embedded: shapes use `currentColor` and can be recolored by SVG editors or CSS. SVG `text` stays editable, but visual metrics depend on font availability. No gradients, raster images, backgrounds, or embedded fonts.

**Preferred mark:** `mingl-compact-mark.svg` for navigation and `mingl-orbit.svg` for feature identity. The original AI-generated mockups were concepts; these are newly constructed editable vector assets.
