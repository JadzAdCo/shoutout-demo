# Cursor instructions — Mingl colorless SVG kit

1. Preserve **Mingl** as a distinct FLOQR brand and feature. **Room SMARTview** is the interactive UI for a Mingl Room. A Mingl Room is a shared collaborative BOT-DEE chat session involving multiple participants with headless process capabilities.
2. Inspect FLOQR's actual Site Chrome tokens and icon pipeline. Inline the provided SVG mark (or use a safe SVG component loader) and inherit CSS `color: var(--existing-floqr-token)`. Do not hardcode cyan, purple, white, black, gradients, or backgrounds into production marks.
3. Each SVG is individually editable and uses `currentColor`. Paths and circles are independent. Wordmarks use live SVG `<text>` for editability; ensure chosen brand font is available or convert to outlines **in a derivative only** after brand typography is approved.
4. Recommended small-size navigation mark: `icons/mingl-compact-mark.svg`; use `icons/mingl-orbit.svg` for larger feature cards; use `logos/mingl-horizontal.svg` for headers. Test at 20, 24, 28, 32, 48, 64, 128 px and on all FLOQR Site Chrome themes.
5. Use labels `Mingl`, `Mingl by FLOQR` in promotional contexts, and `Room SMARTview` for the room UI. Preserve branded terms untranslated.
6. Provide accessible names for meaningful marks; hide decorative repeats from assistive technology. Maintain sufficient contrast in every Site Chrome, including light mode.
7. Do not deploy or modify production without approval.

Note: These are clean, vector redraws inspired by the prior conceptual renderings, **not pixel-perfect vector traces** of raster-generated images.
